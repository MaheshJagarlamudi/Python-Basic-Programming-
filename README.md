
# Python for Mathematics — Learning Notebooks

A structured series of Jupyter notebooks designed to build core Python programming skills through the lens of mathematical applications. Each notebook focuses on a specific concept, progressing from fundamentals to more applied topics.

## 📚 Contents

| # | Notebook | Topic |
|---|----------|-------|
| 01 | `01_Variables_DataTypes_Arithmetic.ipynb` | Variables, data types, and basic arithmetic operations |
| 02 | `02_Strings_MathFormatting.ipynb` | String manipulation and formatting numerical output |
| 03 | `03_Lists_Tuples_Sequences.ipynb` | Working with lists, tuples, and sequence data structures |
| 04 | `04_Dictionaries_Sets.ipynb` | Dictionaries, sets, and their mathematical use cases |
| 05 | `05_ConditionalLogic_MathDecisions.ipynb` | Conditional statements for decision-making in math problems |
| 06 | `06_Loops_MathIteration.ipynb` | Loops and iterative mathematical computation |
| 07 | `07_Functions_MathFormulas.ipynb` | Writing functions to encapsulate mathematical formulas |
| 08 | `08_MathModule.ipynb` | Using Python's built-in `math` module |

## 🎯 Purpose

This series is intended for learners who want to strengthen their Python fundamentals while reinforcing mathematical concepts. Each notebook combines short explanations with hands-on code examples and exercises.

## 🛠️ Requirements

- Python 3.x
- Jupyter Notebook or JupyterLab

Install Jupyter if needed:
```bash
pip install notebook
```

## 🚀 Getting Started

1. Clone or download this repository.
2. Launch Jupyter Notebook:
```bash
   jupyter notebook
```
3. Open the notebooks in order, starting with `01_Variables_DataTypes_Arithmetic.ipynb`.

## 📌 Recommended Order

The notebooks are numbered sequentially and build on one another. It's recommended to follow them in order for the best learning progression, though each can also be used as a standalone reference.
